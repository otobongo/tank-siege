# Controls

## Keyboard

| Action | Player 1 | Player 2 |
|---|---|---|
| Move | Arrow keys | WASD |
| Fire | Space | F |
| Pause | Escape or Enter | Escape or Enter |
| Mute | M | M |

## Gamepad (standard mapping)

| Action | Input |
|---|---|
| Move | D-pad or left stick |
| Fire | Button 0 (A / Cross) |
| Pause | Start (button 9) |

The first connected pad takes the first unassigned player slot. The keyboard
always remains available as a fallback for the remaining player.
